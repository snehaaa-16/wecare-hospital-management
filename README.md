# WeCare Hospital Management System
A full-stack hospital management web application for managing patients, doctors, appointments, and hospital operations, with secure authentication and role based access

## Features
- Patient registration and login
- Appointment booking and management
- Admin dashboard for managing doctors, patients, and appointments
- Role-based access control
- Separate interfaces for patients and administrators

## Tech Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB

## Project Structure
- backend/   - REST APIs and business logic
- frontend/  - Patient-facing web application
- admin/     - Admin dashboard
